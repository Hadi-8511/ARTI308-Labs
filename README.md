# ARTI308 – Lab 4: Data Quality Assessment & Preprocessing

This project performs data cleaning and preprocessing for the **Student Performance Dataset**.

## Objective
Prepare the dataset for modeling by improving data quality and transforming features appropriately.

## Key Steps
- Data inspection and validation  
- Missing value handling  
- Duplicate and outlier detection (IQR & Capping)  
- Encoding categorical features  
- Normalization & Standardization  
- Correlation analysis  
- PCA for dimensionality reduction
