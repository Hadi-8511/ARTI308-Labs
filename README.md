# ARTI 308 – Lab 5: Feature Engineering (Classification)

---

## Overview

This lab applies **feature engineering and machine learning** techniques to predict food delivery **Order_Status** using the `talabat_enhanced_orders.csv` dataset.

---

## Completed Tasks
- **Task 1:** Engineered `distance_per_item` to measure logistical delivery efficiency.
- **Task 2:** Tested an alternative peak hour rule to capture broader high-demand periods.
- **Task 3:** Analyzed the impact of `top_k` categorical reduction on model accuracy.
- **Task 4:** Applied `SelectFromModel`, successfully reducing the feature space by 50% while maintaining ~85.2% accuracy.
